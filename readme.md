# 부산 지하철 역별 이용객 수 지도 분석 앱

Streamlit과 Folium을 활용하여 부산 지하철 역별 이용객 수를 시각화한 웹 애플리케이션입니다. 
`busan_subway.csv` 파일을 업로드하면 이용객 수에 비례하는 크기의 마커와 호선별 색상을 지도에서 직관적으로 확인할 수 있습니다.

**주요 기능**
* CSV 데이터 표 미리보기 및 이용객 수 상위 5개 역 확인
* 원하는 호선만 지도에 띄울 수 있는 필터링 기능
* 이용객 수에 비례하는 마커 면적 시각화 및 호선별 색상 적용
* 마커 상호작용 (마우스를 올리면 역명, 클릭하면 상세 이용객 수 출력)
